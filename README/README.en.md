# Control

"Control" is a GUI application developed in Python to schedule computer shutdown or restart. With a simple and intuitive interface created with Tkinter, you can easily set the time in seconds or choose one of the available options for scheduling. Additionally, you have the option to cancel the action if needed.

## Features

- **Schedule Shutdown/Restart:** Enter the desired time in seconds or select one of the provided options.  
- **Confirm Action:** After setting the time, confirm the action, and the application will take care of the rest.  
- **Cancel Action:** If you change your mind or input an incorrect value, click "Cancel" to stop the scheduling.

## Requirements

1. **Python:** Make sure Python is installed on your system.  
2. **Libraries:** Run the `install_libraries.cmd` file to install the required libraries. During installation, you will be given the option to start the application automatically.  
3. **Running the Application:** After installation, you can start the application by running the `run_script.vbs` file.

## Instructions

1. **Installation:**
   - Run the `install_libraries.cmd` to install the required libraries.  
   - Follow the on-screen instructions to start the application if desired.

2. **Running the Application:**
   - After installation, you can manually start the application by double-clicking the `run_script.vbs` file.

## Notes

- The "Cancel" button is exclusively for stopping any scheduled shutdown or restart actions.  
- Make sure the time entered is correct to avoid unwanted scheduling.
